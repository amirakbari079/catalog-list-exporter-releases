# خروجی لیست کالا

نسخه‌های قابل نصب برنامهٔ ویندوزی خروجی لیست کالا در بخش **Releases** این مخزن منتشر می‌شوند.

## نصب

۱. Python 3.14 نسخهٔ ۶۴بیتی را روی ویندوز ۱۰ یا ۱۱ نصب کنید.
۲. فایل `CatalogListExporter-Setup-v1.1.0-Python314-x64.zip` را از Releases دریافت و کامل استخراج کنید.
۳. `Install.cmd` را اجرا کنید؛ کتابخانه‌ها همراه بسته‌اند و نصب آن‌ها آفلاین است.
۴. از میان‌بر دسکتاپ برنامه را باز کنید.

## به‌روزرسانی

از داخل برنامه دکمهٔ «بررسی به‌روزرسانی» را بزنید. دریافت آپدیت نیاز به اینترنت دارد.
تنظیمات و برندهای کاربر حفظ می‌شوند. نسخه‌های قدیمی بدون این دکمه، یک‌بار به نصب نسخهٔ جدید نیاز دارند.
تغییر کتابخانه‌های اصلی ممکن است نیازمند نصب‌کنندهٔ جدید باشد.

دو فایل `catalog-update.zip` و `catalog-update.json` برای به‌روزرسانی داخل برنامه هستند؛ برای نصب اولیه از بستهٔ Setup استفاده کنید.

این مخزن شامل فایل‌های انتشار است و فایل‌های حسابداری و تنظیمات کاربران در آن قرار نمی‌گیرند.
